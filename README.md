# zyntuner

Low CPU tuner with soft mute and microtonal scales, and spectrum analyser

<img width="400" height="149" alt="image" src="https://github.com/user-attachments/assets/277d79b8-d8f9-4afc-a925-05d9c37a1b84" />

LV2 plugin built with [DPF](https://github.com/DISTRHO/DPF), with a native X11 GUI (Cairo) and a
[zynthian](https://zynthian.org) UI widget (`zyngui:widget`) in the same bundle.

- URI: `urn:riban:tuner`
- License: GPL-3.0-or-later
- **[User guide](docs/USER_GUIDE.md)**: installing, tuning, spectrum analyser, controls, the 18 scales and tunings, troubleshooting

## Build

DPF is a git submodule (`dpf/`) pinned to a tested commit, so the plugin builds the same way in the future.
Clone with `git clone --recursive <repo>`, or in an existing clone:

```
git submodule update --init --recursive
make            # -> bin/zyntuner.lv2
make install    # PREFIX=/usr/local (LV2_DIR=$PREFIX/lib/lv2)
```

Build dependencies: build-essential, pkg-config, libcairo2-dev, libx11-dev, libxext-dev, libxrandr-dev,
libxcursor-dev, libgl-dev. The TTL is generated by running the plugin (`make gen`), so build on the target
architecture.

Prebuilt bundles for x86_64 and arm64 (zynthian) are built by GitHub Actions (`.github/workflows/build.yml`) on
every push: download them from the `latest` prerelease (default branch) or from a `v*` release, and unpack into the
LV2 path (on zynthian: `tar -xzf zyntuner-lv2-arm64.tar.gz -C /zynthian/zynthian-plugins/lv2`).

Updating DPF is a deliberate change: `git -C dpf fetch && git -C dpf checkout <commit or tag>`, build and test,
then commit the new submodule pointer (`git add dpf`).

## Layout

| Path | Contents |
|---|---|
| `plugins/zyntuner/ParamDefs.hpp` | Parameters and port groups (shared by DSP and GUI) |
| `plugins/zyntuner/Plugin.cpp` | DSP |
| `zyngui/zyntuner_scales.py` | Scales and tunings (used by the widget, generates `plugins/zyntuner/Scales.hpp`) |
| `plugins/zyntuner/UI.cpp` | Native GUI |
| `zyngui/` | zynthian widget, help page, `zyngui:widget` declaration, port extras |
| `tools/zyngui_bundle.py` | Adds the zyngui/ files to the bundle after DPF generates it |
| `SPEC.md` | Specification |
